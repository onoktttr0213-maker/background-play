# 正論パンチ（仮） 実装仕様書 Ver.0.7（Claude Code引き渡し用）

このファイルは開発着手用に、確定ルールのみを実装しやすい形でまとめたものです。検討の経緯や過去バージョンとの比較は `正論パンチ_仕様書.md` / `正論パンチ_テストプレイ版ルールブック.md` を参照してください。カードデータは `正論パンチ_cards.json` にJSON形式で同梱しています。

## ゲーム概要
- 2人対戦のカードゲーム。共通山札40枚を2人で共有する
- 勝利条件：相手のライフ4枚をすべて奪う（相手の手札に移させる）

## コンポーネント
- 共通山札：40枚（`正論パンチ_cards.json` 参照）
- ライフ：各プレイヤー4枚（山札から取り分け、裏向きで自分の場に置く）
- 1枚のカードは論破（攻撃）文言と言い訳（防御）文言の両方を持つ多色カード

## カードのデータ構造
```ts
type Attribute = "赤" | "青" | "緑";
type Role = "攻撃型" | "バランス型" | "防御型" | "コンボ型";

interface Card {
  id: string;            // 例: "WK-01"
  theme: string;          // 仕事 / 恋愛 / 健康 / お金 / 人間関係
  role: Role;
  attribute: Attribute;
  attack: number;         // アタック値（攻撃側として使う時）
  defense: number;        // ディフェンス値（防御側として使う時）
  combo: number;          // コンボ値（手札から追加ブーストとして捨てた時のみ加算）
  attackText: string;     // 論破（攻撃）フレーバーテキスト
  excuseText: string;     // 言い訳（防御）フレーバーテキスト
}
```

役割タイプ別の数値（全カード共通）：

| 役割 | attack | defense | combo |
|---|---|---|---|
| 攻撃型 | 5000 | 1000 | 1000 |
| バランス型 | 4000 | 4000 | 2000 |
| 防御型 | 1000 | 5000 | 1000 |
| コンボ型 | 3000 | 3000 | 3000 |

## 属性（3すくみ）
- 赤 > 青 > 緑 > 赤（左が右に対して有利）
- 攻撃側の属性が対象カードの属性に対して有利な場合、**攻撃時のみ** attack に +1000
- 防御側には属性ボーナスは発生しない

```
function hasAttributeAdvantage(attackerAttr, defenderAttr) {
  const beats = { "赤": "青", "青": "緑", "緑": "赤" };
  return beats[attackerAttr] === defenderAttr;
}
```

## 準備フェーズ
1. 40枚をシャッフル
2. 各プレイヤーは山札上から4枚を取り、裏向きライフとして自分の場に置く
3. 先攻は7枚、後攻は8枚ドローして手札にする
4. 各プレイヤーは手札から3枚をベンチに置く
5. 先手決定（じゃんけん等。詳細は未実装でよい仮ルール）

## ターン処理
```
1. ベンチ回復チェック
   直前の相手ターンで自分のベンチ/場のカードが破壊された枚数だけ、
   通常のドローと別枠で追加ドロー → ベンチが3枚になるよう手札から配置

2. ドローフェイズ
   手札が5枚になるまでドロー（上限なし）

3. メインフェイズ
   ベンチ→場、手札→ベンチの補充を必要なだけ行い、
   このターン攻撃に使う分（最大3枚）を場に出す

4. バトル（論破）フェイズ
   場のカードで、相手のベンチ/場のカードに対し最大3回攻撃（1枚につき1回）

5. 手番終了
   このターン使用した場のカードを捨て札へ
   （攻撃側は結果に関わらず全て捨て札／防御側はブロック失敗時のみ捨て札）
```

## バトル処理（1回の攻撃）
```
1. 攻撃宣言
   - 攻撃側：場のカード1枚 + 対象（相手のベンチ/場のカード1体）を宣言
   - 手札から最大3枚まで追加で捨てて combo を上乗せ可能
   - 属性有利なら attack合計 に +1000
   attackTotal = attackerCard.attack
               + (hasAttributeAdvantage(attackerCard.attribute, defenderCard.attribute) ? 1000 : 0)
               + sum(comboCardsFromHand.map(c => c.combo))   // 最大3枚

2. 防御宣言
   - 防御側：場のカード1枚を選択
   - 手札から最大3枚まで追加で捨てて combo を上乗せ可能（属性ボーナスなし）
   defenseTotal = defenderCard.defense + sum(comboCardsFromHand.map(c => c.combo))  // 最大3枚

3. 判定
   if (attackTotal > defenseTotal) {
     // 論破成功
     defender.life -= 1;              // ライフ1枚を裏向きのまま取り除き
     defender.hand.push(removedLifeCard); // 防御側の手札に加える
     discard(attackerCard, attackerComboCards);
     discard(defenderCard, defenderComboCards);
   } else {
     // ブロック成功（defenseTotal >= attackTotal）
     discard(attackerCard, attackerComboCards);
     discard(defenderComboCards);
     // defenderCard は場に残る（捨てない）
   }
```

## 終了条件
- ライフ4枚をすべて失った（手札に移された）プレイヤーが敗北
- 共通山札が尽きたら、両者の捨て札をまとめてシャッフルし新しい山札にする
